# Данные

Датасеты E-CUP 2026 не хранятся в Git из-за их размера и условий распространения. Для воспроизведения обучения их необходимо получить отдельно и разместить локально в этой директории либо указать соответствующие пути в notebook и training-скриптах.

## Ожидаемые файлы

| Файл                  | Назначение                                   | Зафиксированный объём |
| --------------------- | -------------------------------------------- | --------------------: |
| `items.parquet`       | Основной каталог товаров                     |    `13 397 761` строк |
| `items_human.parquet` | Данные товаров для этапов с ручной разметкой |       не зафиксирован |
| `matches_llm.parquet` | Базовый корпус пар с soft labels             |    `11 187 780` строк |
| `matches.parquet`     | Корпус пар с ручной разметкой                |      `365 654` строки |

Указанные количества являются значениями, сохранёнными в метаданных выполненных экспериментов. Они не заменяют проверку фактических локальных файлов перед повторным запуском.

## Локальная структура

Рекомендуемое размещение:

```text
data/
├── README.md
├── items.parquet
├── items_human.parquet
├── matches.parquet
└── matches_llm.parquet
```

Некоторые notebook содержат пути исходной вычислительной среды. Перед повторным запуском их необходимо заменить на актуальные локальные пути без изменения самих данных.

## Роль датасетов

`items.parquet` содержит характеристики товаров, из которых preprocessing формирует текстовое представление.

`matches_llm.parquet` используется первым baseline-кандидатом как готовый входной корпус. Репозиторий не обращается к внешнему LLM API для повторного создания этих labels.

`items_human.parquet` и `matches.parquet` используются на Stage B, где модель дообучается на ручной разметке.

Точные наборы данных и параметры разделения для каждого кандидата перечислены в его `version.json`, README и training-коде.

## Тестовые файлы

Для локальной проверки runtime могут дополнительно использоваться:

```text
items_test.parquet
matches_test.parquet
submit_test.csv
```

Эти файлы являются локальными тестовыми артефактами и также не должны добавляться в Git.

## Проверка перед обучением

Перед запуском необходимо проверить:

* наличие всех файлов, требуемых выбранным кандидатом;
* названия и типы обязательных столбцов;
* количество строк;
* отсутствие случайно изменённых данных;
* доступное место на диске;
* соответствие путей в notebook локальному окружению.

## Хранение

Все Parquet-файлы, тестовые CSV и производные датасеты в этой директории игнорируются Git.

В репозиторий добавляется только этот README. Контрольные суммы или копии закрытых данных не публикуются, если это не разрешено правилами их распространения.
