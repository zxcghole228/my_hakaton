# Финальный выбор BGE-решений

Команда зафиксировала два финальных BGE-кандидата задачи матчинга
товаров E-CUP 2026.

| Место | Кандидат | Public macro PR-AUC |
|---:|---|---:|
| 1 | `bge_stage_b_v3_cross_soup_symmetry_tta` | 0.5539900397479464 |
| 2 | `bge_stage_b_v2_checkpoint_soup` | 0.5520634383301408 |

Машиночитаемая фиксация выбора, SHA-256 весов и локально собранных
runtime-архивов находится в `final/selection.json`.

## Статус архивов

Оба исправленных runtime-архива собраны локально и проверены:

- структура ZIP;
- единственный корневой каталог;
- `metadata.json`;
- `run.py`;
- отсутствие небезопасных путей и служебных файлов macOS;
- SHA-256 встроенного `model.safetensors`.

Архивы и веса не добавляются в Git из-за размера. Для повторной сборки
используются candidate-specific файлы
`construction/runtime/build_submit.py`.

## Важное ограничение

Public leaderboard scores относятся к историческим submission,
связанным с указанными весами. Исправленным runtime-архивам эти scores
не приписываются как результат отдельного повторного запуска на
площадке.

Идентификаторы submission платформы не были сохранены и поэтому
остаются явно отмечены как отсутствующие.
