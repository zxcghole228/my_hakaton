# Финальный выбор BGE-решений

Команда зафиксировала два финальных BGE-кандидата задачи матчинга
товаров E-CUP 2026.

| Место | Кандидат | Public macro PR-AUC |
|---:|---|---:|
| 1 | `bge_stage_b_v3_cross_soup_symmetry_tta` | 0.5539900397479464 |
| 2 | `bge_stage_b_v2_checkpoint_soup` | 0.5520634383301408 |

Машиночитаемая фиксация выбора, SHA-256 весов и локально собранных
runtime-архивов находится в `final/selection.json`.

## Статус архивов

Финальные локальные архивы собраны и проверены:

- V2 использует исправленный runtime-сборщик;

- V3 использует точный fixed-runtime, восстановленный
  из сохранённого фактического solution;

- для V2 проверяется единственный корневой каталог,
  а V3 создаётся как плоский ZIP;

- проверяются `metadata.json`, `run.py`, структура и
  отсутствие небезопасных либо служебных файлов macOS;

- проверяется SHA-256 каждого внутреннего файла,
  включая `model.safetensors`.

Архивы и веса не добавляются в Git из-за размера.

Для V2 используется:

```text
construction/runtime/build_submit.py
```

Для выбранного V3 используются:

```text
construction/fix/runtime
construction/fix/build_submit.py
```

Подробная история ручного исправления находится в
`construction/fix/sad_story.md`.

## Важное ограничение

Public leaderboard scores относятся к историческим submission,
связанным с указанными весами. Исправленным runtime-архивам эти scores
не приписываются как результат отдельного повторного запуска на
площадке.

Идентификаторы submission платформы не были сохранены и поэтому
остаются явно отмечены как отсутствующие.
