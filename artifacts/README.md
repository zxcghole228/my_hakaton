# Локальные артефакты

Каталог для готовых архивов, распакованных сборок и экспортов экспериментов.
В Git хранится только этот README; всё остальное исключено по `.gitignore`.

```text
artifacts/
├── submissions/          # готовые ZIP для загрузки в систему соревнования
├── submission_builds/    # временные распакованные сборки перед упаковкой
└── experiment_exports/   # исходные bundles с результатами экспериментов
```

Правила:

1. Исходный код решения хранится в `solutions/<solution_name>/`.
2. Метрики и небольшие таблицы распаковываются в `experiments/<experiment_name>/`.
3. Большие ZIP, веса и промежуточные сборки остаются только в `artifacts/`.
4. Имя submission-архива должно совпадать с именем решения, если формат
   соревнования не требует другого имени.
