# Откуда брать данные (в git не влезают: лимит GitHub 100MB/файл)

## Для финальных ноутбуков (final_e5base_320_hardprep / final_bge_m3_320)

Нужны ровно 2 файла:

| Файл | Размер | Где взять |
|---|---|---|
| items.parquet | 4.1GB | страница «Данные» соревнования E-CUP (полные данные о товарах) |
| matches_llm.parquet | 105MB | там же (разметка пар с помощью LLM) |

Альтернатива, если сайт соревнования неудобен: Kaggle-датасет Михаила
"Hakaton Ozon math items" (те же файлы) — скачать через браузер с kaggle.com.

## Что уже лежит в репо (маленькое)

| Файл | Что это |
|---|---|
| data_polygon/llm_sample_2m.parquet (20MB) | полигон для быстрых абляций |
| labeling/pilot_pairs.parquet (19MB) | пилот разметки, с человеческим золотом |
| labeling/battle_pairs.parquet (66MB) | боевые пары разметки v1 (после починки пилота) |

## Прочие файлы соревнования (для других задач)

- matches.parquet (4MB) — ручная разметка, со страницы соревнования
- items_human.parquet (215MB) — подмножество товаров ручной разметки, там же

Контрольные размеры после скачивания: matches_llm = 11,187,780 строк,
items = 13,397,761 строк. В ноутбуках стоят assert'ы на сплиты — если данные
не те, упадёт сразу, а не после часов обучения.
