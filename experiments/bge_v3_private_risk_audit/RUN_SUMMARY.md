# BGE V3 Private-Risk Audit

## Статус

- Дата запуска: 2026-08-26.
- Запуск завершён успешно за 61.55 минуты на `2 x Tesla T4`.
- Проверяемая модель: `ECUP Product Matching BGE V3`, public LB `0.5535`.
- Итоговый уровень риска: **MEDIUM**, 3 risk points.
- Ноутбук с кодом и полными логами: [`notebooks/runs/bge_v3_private_risk_audit_run.ipynb`](../../notebooks/runs/bge_v3_private_risk_audit_run.ipynb).

## Цель

Эксперимент не пытался дополнительно улучшать public leaderboard. Цель — проверить, насколько текущий лучший BGE V3 устойчив к переходу с public на private части теста и нет ли у локальной оценки явных признаков leakage или переобучения.

Настоящие private labels недоступны, поэтому результат является оценкой риска, а не прогнозом точного private LB.

## Методика

1. Использован exact preprocessing из submission-контейнера с LB `0.5535`.
2. Human labels разделены по связанным компонентам товаров:
   - train: 292,428 пар;
   - tune: 36,609 пар;
   - eval: 36,617 пар.
3. Восстановлен независимый LLM holdout из 191,555 high-confidence пар с component split `seed=13`.
4. Проверено прямое пересечение unordered human tune/eval пар с LLM train.
5. Инференс выполнен с `max_length=320` и swap-TTA: среднее `P(a,b)` и `P(b,a)`.
6. Untouched human eval 500 раз разбивался на псевдо-public 30% и псевдо-private 70% без пересечения item-компонентов.
7. Отдельно проанализированы все 20 категорий и устойчивость к перестановке товаров в паре.

## Основные результаты

### Human validation

| Срез | Macro PR-AUC |
|---|---:|
| Tune | 0.800427 |
| Untouched eval | 0.786115 |
| Eval − tune | **−0.014312** |
| Clean tune, без LLM pair overlap | 0.800427 |
| Clean eval, без LLM pair overlap | 0.786115 |

Human eval заметно ниже tune. Это главный аргумент в пользу риска умеренной private-просадки.

Разница между независимыми половинами меньше `0.01`, поэтому на LLM distribution модель выглядит устойчиво.

### Leakage audit

| Human split | Прямое пересечение пар с LLM train |
|---|---:|
| Tune | 0.0% |
| Eval | 0.0% |

Прямого pair leakage не обнаружено. Human eval можно считать чистым относительно LLM train на уровне размеченных пар.

| Показатель | Значение |
|---|---:|
| Median pseudo-private | 0.786153 |
| P10 pseudo-private | 0.781819 |

Симуляция не показывает риска катастрофического обвала относительно ожидаемого качества модели. При этом public subset способен оказаться заметно оптимистичнее private примерно в четверти разбиений.

| LLM | 0.01340 | 0.05765 |

Swap-TTA оправдан: отдельные пары чувствительны к порядку, но средняя асимметрия небольшая.

## Вывод

У BGE V3 нет признаков leakage или общего разрушения качества. LLM holdout и псевдо-private симуляция стабильны, а вероятность падения локального Macro PR-AUC больше чем на `0.01` относительно полного eval в проведённых разбиениях равна нулю.

Однако human eval ниже tune на `0.0143`, а семь категорий нестабильны. Поэтому точное сохранение public LB `0.5535` на private не гарантируется; умеренная просадка на несколько тысячных правдоподобна.

Решение для финала:

1. Оставить BGE V3 `0.5535` основным финальным submission.
2. Если разрешено выбрать два финальных submission, использовать предыдущий BGE V2 `0.5515` как резервный hedge.
3. Не добавлять category-specific веса и новые public-tuned микробленды перед private.
4. Не заменять BGE V3 незавершённым Stage-B V2.1 без отдельного untouched подтверждения.

## Ограничения

- Private labels недоступны, поэтому точный private score вычислить невозможно.
- Локальный Macro PR-AUC нельзя напрямую переводить в шкалу leaderboard.
- Псевдо-private симулирует sampling variance, но не неизвестный distribution shift Kaggle test.
- Public LB уже использовался при выборе предыдущих решений, поэтому полностью исключить researcher overfitting невозможно.
