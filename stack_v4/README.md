# Стек v4: конвейер (Даниил — шаг 1 на GPU, Егор — шаги 2-3 на CPU)

## Разделение труда

| Шаг | Что | Где | Время |
|---|---|---|---|
| 1 | Скоринг всех пар моделью e5-base@320 | Даниил, A100 | ~40-60 мин (без TTA) |

## Даниилу: шаг 1

```bash
python 1_score_e5_oof.py \
  --model ./e5base_320_run/export \
  --items ./items.parquet \
  --matches-llm ./matches_llm.parquet \
  --matches-manual ./matches.parquet \
  --items-human ./items_human.parquet \
  --out ./v4_scores
```

- hardprep build_text вшит в скрипт (побайтово из обучения) — ничего не менять.
- Чанки с резюме: обрыв — перезапуск, готовые пропустятся.
- TTA не нужен (для фичи хватает одного направления); если очень хочется — --tta (x2).
- Прислать: папку v4_scores (12 чанков + manual_scores.parquet, суммарно ~150MB).

## Про OOF (важно, это ответ на Ваше замечание о leakage)

Честный K-fold OOF = K переобучений e5 (~50 GPU-часов) — не окупается. Компромисс:
скорим единой моделью, а в train стека добавляем флаг is_seen (пара участвовала
в обучении e5). CatBoost выучит поправку на in-sample-оптимизм скора; на
инференсе is_seen=0 для всех пар теста — модель применит "честную" ветку.
Замерим эффект: в v3 non-OOF стек всё равно дал +0.011 LB к соло; сравнение
v4 с/без is_seen покажет остаток.

Если после bge-m3 останутся GPU-часы и желание — настоящий 3-fold OOF
(3 переобучения e5 по ~5 ч) как v4.1, но это роскошь.

## Что войдёт в стек v4 (Егор)

- 96 фичей (63 базовых + 32 features_v2) — готовы;
- ce_score e5-base@320 (шаг 1) — главная фича;
- ce_score tiny-2ep — вторая CE-фича (уже отскорено, диверсити);
- SBE bi-encoder фичи (косинус + |d| статистики) — скорится на маке;
- is_seen флаг; confidence weighting; обучение на llm-train + manual вес 5;
- eval на llm-holdout (seed 13), отчёт также на manual holdout.

Прогноз: e5 соло LB 0.5091; стек v3 давал +0.011 к своему соло -> v4 ~0.515-0.52.
