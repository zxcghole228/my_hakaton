# Уважаемому Даниилу: скоринг bge для стека v5 — пошагово

## Зачем

Стек v5 = CatBoost поверх [96 фичей + скор bge + скор e5 + SBE]. Ваши bge-скоры
на 11.2M llm-пар + 365k manual-пар — последний недостающий вход. Скоры e5 мы уже
посчитали на маке (прислали архивом e5_scores_for_danya.tar.gz, 97MB — пригодятся
Вам, если захотите свой стек/бленд собрать; распаковать рядом: tar -xzf).

## Шаг за шагом (на боксе, где лежит bge-экспорт; ~40-60 мин на H100)

1. Забрать скрипт (он уже в репо):
   stack_v4/1_score_e5_oof.py — универсальный, модель задаётся флагом.
   Если репо неудобно — файл можно взять из архива e5_scores... нет, лучше
   попросите Егора прислать файл напрямую.

2. Запуск (подставьте свои пути):
```bash
python 1_score_e5_oof.py \
  --model ./bge_m3_320_run/export \
  --items ./items.parquet \
  --matches-llm ./matches_llm.parquet \
  --matches-manual ./matches.parquet \
  --items-human ./items_human.parquet \
  --out ./v5_scores
```
   - --model: папка Вашего bge-экспорта (config.json + model.safetensors +
     tokenizer). Именно та, из которой Вы отдавали нам веса.
   - hardprep build_text вшит в скрипт побайтово из обучения — НЕ менять.
   - TTA не нужен (--tta существует, но для фичи стека хватает одного прохода).

3. Что произойдёт: сначала manual (365k, ~2 мин), затем 12 чанков llm по 1M
   с резюме — обрыв безопасен, перезапуск продолжит с готового чанка.

4. Прислать: папку v5_scores целиком (12 файлов llm_chunk_XX.parquet +
   manual_scores.parquet, суммарно ~130-150MB). Любым способом, как веса.

## Известная ловушка

Если экспорт после vocab-trim: скрипт подхватит Ваш tokenizer из папки модели
автоматически — ничего настраивать не надо. Но если tokenizer в папке экспорта
отсутствует (только веса) — доложите его туда из прогона, иначе AutoTokenizer
упадёт или, хуже, молча возьмёт другой.
